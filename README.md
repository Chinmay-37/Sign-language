# Sign Language Recognition Project

This project uses a machine learning model for **ASL (American Sign Language)** recognition.

## Model Files

The model files are too large to be uploaded directly to GitHub. You can download them from Google Drive using the links below:

- [Download ASL CNN Model](https://drive.google.com/file/d/1QTKlsI_gL68Pq5O5koofkRud7aiTGgkK/view?usp=drive_link)
- [Download Gesture Recognition Model](https://drive.google.com/file/d/1HXKiGPf2AlKle4Lfwl-23zKO-XdKN7lZ/view?usp=drive_link)

## Full Project Files

The complete project files, including the models and other assets, can be downloaded from the following Google Drive folder:

- [Download Full Project](https://drive.google.com/drive/folders/1ZuFiPhUxGyWLMLa_5zgV-q6VV74ahn_u?usp=sharing)

Make sure to place the downloaded models in the `models/` directory in your project.
